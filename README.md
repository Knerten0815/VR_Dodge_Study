# VR_Dodge_Study

This bachelor thesis is researching how people are dodging objects in VR and how their movement can benefit resetting techniques in redirected walking.
The project was forked from [OpenRDW](https://github.com/yaoling1997/OpenRDW).

Take a look at the [paper](https://doi.org/10.18420/vrar2023_3368) and [thesis]([https://media.licdn.com/dms/document/media/D4E2DAQEW87hYI4jmpA/profile-treasury-document-pdf-analyzed/0/1724065576347?e=1724889600&v=beta&t=CnXXQx5PDYDc84ZcWK2Gg6qfDOYPFYAnIujh8D-1nRk](https://www.linkedin.com/in/kevinzielke/details/education/870417127/multiple-media-viewer?profileId=ACoAAEHbsTsBw_sE-5WbzQXzJBVX0RPaEcmmQHM&treasuryMediaId=1724065980292&type=DOCUMENT&lipi=urn%3Ali%3Apage%3Ad_flagship3_profile_view_base_education_details%3BFeMV60a8QAqu83G5%2BlyX3w%3D%3D)) (german) developed from this project.

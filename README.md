# VR_Dodge_Study

This bachelor thesis is researching how people are dodging objects in VR and how their movement can benefit resetting techniques in redirected walking.
The project was forked from [OpenRDW](https://github.com/yaoling1997/OpenRDW)

Take a look at the [paper](https://doi.org/10.18420/vrar2023_3368) and [thesis](https://media.licdn.com/dms/document/media/D4E2DAQEW87hYI4jmpA/profile-treasury-document-pdf-analyzed/0/1724065576347?e=1724889600&v=beta&t=CnXXQx5PDYDc84ZcWK2Gg6qfDOYPFYAnIujh8D-1nRk) (german) developed from this project.
